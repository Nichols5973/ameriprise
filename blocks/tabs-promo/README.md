# tabs-promo

Custom **tabs** block. Purpose: resource tabs.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: tab label | heading + paragraph | image and/or optional video link (Brightcove/YouTube/Vimeo/mp4) | footer line.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
